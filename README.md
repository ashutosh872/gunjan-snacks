## 🌟 Concept & Social Dine-In Experience

**Gunjan Snacks** brings the vibrant street-food culture to life with a contactless social dine-in flow:

> **"VISIT • SCAN • BOOK • GET ON TABLE"**

Customers visit either of our outlets, scan the hero QR standee with their smartphone camera, browse our authentic 100% Pure Veg menu, select their table or takeaway counter, and place their order. The kitchen and owner (`9310681373`) immediately receive the verified order with token number, table designation, itemized list, and customer phone via WhatsApp.

## 🛠️ Technology Stack

- **Frontend:** React 19, Vite 8, Tailwind CSS v4
- **Icons & Visuals:** Lucide React, Canvas Confetti
- **QR Engine:** Dynamic high-contrast QR generation (`qrcode`), camera barcode reading (`jsqr`)
- **Direct Dispatch:** Instant WhatsApp API integration sending orders to owner hotline `9310681373`
- **Hosting & CI/CD:** GitHub Pages with GitHub Actions automated deployment
